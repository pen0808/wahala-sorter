# Effect of removing a line of code

In the App.jsx file, I removed the line `const [tasks, setTasks] = useState([])`. This line initializes the state of the application with an empty array.

The removal of this line results in an error in the application.

# Effect of adding back the line of code

In the App.jsx file, I added the line `const [tasks, setTasks] = useState([])`. This line initializes the state of the application with an empty array.

Adding back the line of code results in the application working as expected.
